# Android-приложение

Это Flutter-клиент закрытого пилота «Комплаенс-Навигатора». Приложение подключается к REST API сайта `https://compliance-pilot.ms777.ru/api/v1/`. В репозитории нет исходников сервера, учётных данных к службам, карточек организаций или ключа подписи.

В приложении можно вести сведения об организациях, заполнять анкету, разбирать задачи, хранить документы и готовить отчёты. Доступ к данным ограничен членством в организации. Вносите только те сведения, которые вправе обрабатывать. Помощник работает на сервере через подписку владельца; персональные данные в AI передавать нельзя.

Скачать подписанный APK можно на [странице Android-приложения](https://compliance-pilot.ms777.ru/android/). Проверить обновления можно и в разделе **Настройки → Обновление приложения**. Установку подтверждает сам пользователь. В Google Play приложение не публикуется.

Закреплённые версии инструментов, команды проверок и сборки описаны в [руководстве для разработчиков](../docs/development.md). [Снимок API](../docs/api/openapi-v1.json) и [токены дизайна](../docs/android-design-green-v1.tokens.json) описывают контракт и оформление приложения.

Будем рады советам и пожеланиям. В примерах и сообщениях об ошибках используйте вымышленные данные и не добавляйте сведения о реальных людях, пароли или ключи. [Оставить предложение](https://github.com/ub3dqy/ComplianceNavigato-Android/issues/new).
